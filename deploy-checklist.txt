📋 部署前准备

  本地环境:
  □ Node.js 已安装 (>=14.17)
  □ Docker Desktop 已运行
  □ SSH 客户端可用
  □ 已编译项目: npm run build

  云服务器准备:
  □ 已购买云服务器 (阿里云/腾讯云/AWS等)
  □ 操作系统: Ubuntu 20.04+ 或 CentOS 7+
  □ 配置: 最低 1核1GB (推荐 2核2GB)
  □ Docker 已安装
  □ 端口 80 已在安全组/防火墙开放
  □ SSH 访问已配置 (密钥或密码)

🚀 部署步骤

  步骤 1: 准备本地环境
  □ 打开终端/PowerShell
  □ 进入项目目录: cd d:\AI\coordinate-picker
  □ 编译代码: node node_modules\typescript\bin\tsc
  □ 验证文件: index.html, index.js, nginx.conf

  步骤 2: 执行部署
  □ 运行部署脚本: deploy-windows.bat 服务器IP 80
  □ 或手动步骤:
      □ docker build -t coordinate-picker:latest .
      □ docker save coordinate-picker:latest | gzip > app.tar.gz
      □ scp app.tar.gz root@服务器IP:/tmp/
      □ ssh root@服务器IP
      □ docker load < /tmp/app.tar.gz
      □ docker run -d -p 80:80 --name coordinate-picker \
           --restart always coordinate-picker:latest

  步骤 3: 验证部署
  □ 访问: http://服务器IP
  □ 测试健康检查: http://服务器IP/health
  □ 检查容器状态: ssh root@服务器IP "docker ps"
  □ 查看日志: ssh root@服务器IP "docker logs coordinate-picker"

🔧 故障排查

  如果遇到问题:
  
  □ 问题: 无法访问应用
    → 检查防火墙/安全组
    → 检查容器是否运行: docker ps
    → 检查端口映射: docker port coordinate-picker
  
  □ 问题: 容器启动失败
    → 查看日志: docker logs coordinate-picker
    → 检查镜像: docker images
    → 重新构建: docker build -t coordinate-picker .
  
  □ 问题: 健康检查失败
    → 进入容器: docker exec -it coordinate-picker sh
    → 测试: curl http://localhost/health
    → 检查 nginx: nginx -t
  
  □ 问题: 性能问题
    → 查看资源: docker stats coordinate-picker
    → 调整限制: 编辑 docker-compose.prod.yaml
    → 重启容器: docker restart coordinate-picker
